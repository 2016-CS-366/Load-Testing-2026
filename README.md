# Load-Testing-2026
Load Testing of Sign Up workflow in jMeter where OTP verification and Payment workflow is included in it.
This load testing is done in jmeter for verifying sign up workflow for 100 users in 60 seconds.
The sign up workflow has Reisteration page which takes email from user and then send verification code to the provided email which is OTP verification. Then, there is Payment verification involved with Stripe.
This test cover all the steps in Sign Up workflow.
